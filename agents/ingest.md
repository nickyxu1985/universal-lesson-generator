# ingest.md — 找資料（Cue）

- **角色**：依主題自己找官方／技術文件，抓 5 個以上來源。
- **輸入**：主題（`topics/topic.yaml`）、受眾（只影響取捨，不影響找不找）。
- **輸出**：來源清單（URL、抓取日期、標題）＋抓取 log，貼回 Slack thread。
- **檢查標準（由 verifier / Instinct 驗，不由自己驗）**：HTTP 200、內文非空、跟主題有關、去重、官方／技術文件優先。
- **失敗處理**：不合格就換下一個來源重抓，直到 5 個有效來源；來源用完還不夠就回報，不要腦補。
- **不能做的事**：不寫 Wiki、不寫教案、不寫簡報；不把模型記憶當來源，沒抓到的就說沒抓到。
- **通道**：Cue 沒接 Slack，任務經 mail 來回；回來的資料由 Nicky 或 n8n 轉貼回 thread。
