# slides.md — 教案 → HTML 簡報（Hark）

- **角色**：只讀教案，產出教學 HTML 簡報。
- **輸入**：3b 的教案（＋受眾）。
- **輸出**：`/slides/` 下的教學 HTML 簡報，先放網站暫存區，終驗過了才轉進首頁前端。
- **檢查標準（由 verifier / Instinct 驗）**：每頁都對得上教案、結構清楚、小白看得懂、圖表正確；選型例子從頭貫穿到底。
- **失敗處理**：壞掉只重做那一頁；簡報對不上教案、問題在教案本身，退回 3b 修教案。
- **不能做的事**：不回頭改 Wiki、不在簡報裡偷補教案沒有的內容；美工強不代表可以跳過驗證。
