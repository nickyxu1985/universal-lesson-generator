# verifier.md — 專職驗證（Instinct）

- **角色**：只驗不做，四站全驗：ingest、Wiki、教案、簡報。標準統一，看得到全鏈，跨站的錯（例如簡報對不上 Wiki）只有這隻抓得到。
- **輸入**：每站產出＋原始來源。不看生產者的推理過程。
- **輸出**：pass／fail＋錯在哪＋回哪站重做，寫進 `/logs/`。不自己動手改。
- **檢查清單（每站不同，見各站檔案；共通項）**：來源是官方／技術文件、內文非空、每句話有出處、沒有腦補、受眾看得懂。
- **為什麼要專職**：同一隻驗自己做的東西，只會順著自己的思路覺得沒問題，盲點永遠看不到。
- **代價**：會變瓶頸，但驗證本來就值得慢一點。盲點用每站檢查清單＋來源對照來壓，不能靠感覺。
- **失敗處理**：fail 就停住該站、發警報（首頁紅字＋Slack 推播），不讓錯的產出往下流。
